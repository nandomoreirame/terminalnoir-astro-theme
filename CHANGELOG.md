## [0.0.1] - 2026-10-23

### Added

- Add a standalone static Astro starter for developer tools and open-source projects.
- Add Noir and Paper visual modes, local fonts, semantic color tokens and a component showcase.
- Add English and Brazilian Portuguese pages for Home, About, Docs and integrations with individual detail pages.
- Add validated product configuration, localized calls to action and replaceable integration examples.
- Add sanitized Markdown with local Shiki highlighting, code-copy controls, keyboard-accessible tabs and screenshot
  previews.
- Add canonical URLs, language alternates, Open Graph metadata, sitemap and robots with subdirectory deployment support.
- Add CI coverage for unit tests, content validation, browser interactions, accessibility and isolated installation
  builds.
- Add installation, customization, deployment and contribution documentation under the MIT license.

### Fixed

- Fix missing author attribution with a footer link to nandomoreira.dev's GitHub profile.
- Point default repository links to the Terminal Noir Astro Theme source repository.
